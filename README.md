# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes PDF resumes and provides ATS-based resume insights.

 

- 📄 Upload PDF resume
- 📊 Calculate ATS score
- 🧩 Detect technical skills
- 🎯 Compare resume with Job Description
- ✅ Show matched skills
- ❌ Show missing skills
- 💡 Provide resume improvement suggestions
- 📑 Display extracted resume text
- 📱 Responsive web interface

## 🛠️ Tech Stack

- Python
- Flask
- HTML5
- CSS3
- PyMuPDF
- Jinja2
